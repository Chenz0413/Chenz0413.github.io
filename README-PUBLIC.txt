This folder is the clean public website copy.

Upload the contents of this folder to a static host such as Cloudflare Pages,
Netlify, GitHub Pages, Vercel static output, or your university web space.

Included:
- HTML pages
- CSS and JavaScript needed by the public site
- public images, logos, gallery files, project assets, and background music
- basic browser-side protections against dragging and right-click saving images
- static-host headers in _headers for hosts that support them

Not included:
- backup folders
- preview screenshots
- extracted resume text
- local working notes

Important limitation:
A public website cannot fully prevent visitors from accessing files that their
browser must download to display the page. These protections discourage casual
saving and direct indexing, but they cannot stop screenshots, developer tools,
network capture, or browser cache extraction.
